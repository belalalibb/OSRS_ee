النماذج المقترحة Account/Session/Lease/Command/Event/Approval/Artifact/Recipe/Outbox. التخزين لم يعتمد: SQLite توصية،وJSON بديل مشروط؛لا بيانات حسابات أوأسرار في الحزمة.

GitHub ألغى التفويض المحفوظ وأعاد Reconnect Required. يجب على المالك فتح إعدادات GitHub في Genspark والضغط على Reconnect والموافقة ثم تأكيد الإتمام. لا تعاد محاولة GitHub قبل ذلك. الاعتماد المنشور مكشوف ويجب إلغاؤه؛لا ترسل بديله.

بعد العودة: افحص remote الحالي دون افتراض فراغه،واحفظ تاريخه،وارفع الوثائق بطريقة عادية وتحقق من SHA والمحتوى،ثم ابدأ S01 schemas/fixtures/tests offline دون طلب موافقة عامة إضافية. لا كود تطبيق قبل نشر الأساس المتحقق،ولا حسابات حقيقية/بيع/نقل ضمن التفويض.

غير المنفذ: V01–V08 للتحقق من ادعاءات المصدر؛قراراتstorage/OS/auth؛جميع شرائح التطبيق والاختبارات التشغيلية. لا ضمان anti-ban أوأرباح أوعدد نوافذ من أرقام التقارير.
